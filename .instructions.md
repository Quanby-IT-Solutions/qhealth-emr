# QHealth EMR - Agent Configuration

This file registers custom agents for the workspace. Agents are defined in `.claude/agents/` and automatically discovered by VS Code's Copilot.

## Custom Agents

The following agents are available for this monorepo:

- **backend-developer** — NestJS backend work, oRPC endpoints, Drizzle schema
- **web-frontend-developer** — Next.js frontend, React components, TanStack Query  
- **fullstack-developer** — Cross-layer work spanning contracts, backend, and frontend
- **code-reviewer** — Code reviews and quality checks
- **devops-infra** — Infrastructure, deployment, CI/CD
- **flutter-expert** — Flutter mobile app development

## How to Use

Invoke agents directly in Copilot chats or use the `@` symbol to reference them:

```
@backend-developer Add a new todos endpoint
@fullstack-developer Add reminders feature across all layers
@web-frontend-developer Create the dashboard page
```

## Workspace Structure

This is a Turborepo monorepo with:
- `apps/web` — Next.js 16 frontend
- `apps/backend` — NestJS API server
- `apps/mobile` — Flutter mobile app
- `packages/auth` — Better Auth configuration
- `packages/db` — Drizzle ORM + PostgreSQL
- `packages/contracts` — API contracts & Zod schemas

See [AGENTS.md](./AGENTS.md), [CLAUDE.md](./CLAUDE.md), and `.claude/agents/` for detailed agent documentation.
